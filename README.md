# طلبات Golden Mark — تطبيق PWA

تطبيق داخلي لإدارة أسعار منتجات **الأثر الذهبي للاستيراد والتصدير** وتجهيز طلبات الشراء للعملاء.

---

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق |
| `app.js` | منطق التطبيق (الأسعار، التوليد، التثبيت) |
| `data.js` | بيانات الكتالوج: 43 صنفاً + الصور + الباركودات + سلالم الوحدات |
| `client-template.js` | قالب الملف الذي يُرسل للعميل |
| `manifest.json` | تعريف التطبيق للتثبيت على الشاشة |
| `service-worker.js` | التخزين المؤقت والعمل بدون إنترنت |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | أيقونات التطبيق |

**كل المسارات نسبية** — يعمل التطبيق تحت أي اسم مستودع دون تعديل.

---

## الرفع على GitHub Pages

1. أنشئ مستودعاً جديداً (مثلاً `golden-order`) — **Public**.
2. ارفع كل الملفات أعلاه في **جذر** المستودع (لا داخل مجلد).
3. `Settings` ← `Pages` ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
4. انتظر دقيقة، ثم افتح: `https://<حسابك>.github.io/golden-order/`

## التثبيت على الشاشة

افتح الرابط بمتصفّح Chrome على الجوال ← زر **⬇️ تثبيت** بالأعلى، أو من قائمة المتصفّح ← **إضافة إلى الشاشة الرئيسية**.

## طريقة العمل

**عندك (التطبيق المثبّت):**
- أدخل **سعر أكبر وحدة** لكل صنف (كرتونة أو باكيت حسب الصنف).
- أسعار الوحدات الأصغر تُحسب تلقائياً وتظهر تحت الخانة.
- الأسعار تُحفظ على جهازك فوراً — لا ملفات ولا إعادة إدخال.
- تأكّد من رقم واتساب استلام الطلبات.
- اضغط **📤 تجهيز نسخة للعميل** ← ينزّل ملف HTML.

**عند العميل (الملف المُرسل):**
- أرسل الملف عبر واتساب (📎 إرفاق ← مستند). **النسخة نفسها تصلح لأي عدد من العملاء.**
- العميل يفتح الملف، يختار الوحدة والكمية — والسعر يتغيّر حسب الوحدة المختارة.
- يضغط **📲 إرسال عبر واتساب** ← يصلك الطلب على رقمك.

عند تغيّر الأسعار: افتح التطبيق، عدّل ما تغيّر، وجهّز نسخة عميل جديدة.

---

## سلالم الوحدات

لكل صنف قائمة وحدات خاصة به، وسعر كل وحدة = سعر وحدة السعر ÷ عدد الوحدات.

| مثال | وحدة السعر | الوحدات الأصغر |
|---|---|---|
| سوبر رينج 14g | كرتونة | كيس (÷5) · حبة (÷150) |
| جاكر 110g | كرتونة | علبة (÷14) |
| بار شوفان 30g | باكيت | حبة (÷24) |

لتعديل السلالم: عدّل مصفوفة `units` للصنف داخل `data.js`.

---

## تحديث الملفات لاحقاً

بعد رفع أي تعديل، غيّر رقم النسخة في `service-worker.js`:

```js
var CACHE = 'gm-orders-v2';   // ارفع الرقم مع كل تحديث
```

وإلا سيظل المتصفّح يعرض النسخة القديمة المخزّنة.

## ملاحظة على باركودين

الرقمان التاليان كما وردا في الكتالوج، وخانة التحقق فيهما غير مطابقة لمعيار EAN-13 — يُنصح بمطابقتهما مع المنتج الفعلي:

- **TQ — بار أوت شوكو أصلي 15g**: `693005865098` (12 خانة فقط)
- **جاكر — أعشاب بحرية**: `9556023221091`

الباركودات مولّدة بترميز **Code128** ليطابق الرقم المطبوع تماماً ويبقى قابلاً للمسح.
